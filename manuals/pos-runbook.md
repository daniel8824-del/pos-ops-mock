# POS 운영 매뉴얼 — 강의 시연용 mock

본 매뉴얼은 강의용 mock. 실제 운영 매뉴얼 형식 예시.
학습자 본인 매뉴얼을 QMD/yucrates에 ingest하면 동일 흐름으로 검색 가능.

## §1 매장 운영 시간

- 평일 09:00 ~ 22:00 (매장별 차이 있음, `stores.csv` 참조)
- 주말 10:00 ~ 23:00 (홍대점만 11:00 시작)
- 마감 정산: 22:30 ~ 23:00

## §2 결제 관련

### §2.1 결제 단말 timeout (TERMINAL_TIMEOUT)

증상: 카드 승인 응답이 30초 이상 걸림.

조치 절차:
1. 단말 화면 확인 — 통신 상태 표시 점검
2. 매장 wifi 재연결 (라우터 power cycle 30초)
3. 단말 자체 재부팅 (전원 5초 long press)
4. 카드사 VAN 연동 상태 확인 (본사 IT 010-0000-1234)
5. 백업 결제 수단 안내 (모바일 페이 권장)

### §2.2 카드 승인 거부 (PAYMENT_FAIL)

증상: "한도 초과" 또는 "카드사 거부" 메시지.

조치:
- 1차: 다른 카드 권유 (정중하게)
- 2차: 카드사 ARS 안내 (1588-...)
- 3차: 현금 또는 간편결제 안내
- 금일 동일 카드 5회 이상 실패 시: 카드 부정 사용 의심, 매니저 호출

## §3 POS 단말 장애

### §3.1 POS 단말 응답 없음 (POS_DOWN)

증상: 화면 freeze, 입력 무반응.

조치 절차:
1. 단말 power cycle (5초 전원 off → on)
2. 5분 후 미복구 시 본사 IT 010-0000-1234
3. 복구 동안 백업 단말로 결제 진행 (매장당 1대 비치)
4. 1시간 이상 미복구 시 현장 IT 출동 요청

### §3.2 프린터 영수증 출력 실패

조치:
1. 용지 잔량 확인
2. 프린터 헤드 재장착
3. 단말 재부팅
4. 미복구 시 모바일 영수증으로 대체

### §3.3 바코드 스캐너 인식률 저하

조치:
1. 스캐너 렌즈 청소 (마른 천)
2. 케이블 연결 재확인
3. 수동 SKU 입력으로 임시 대응
4. IT 교체 요청

## §4 재고 관련

### §4.1 재고 부족 (STOCK_SHORTAGE)

증상: 시스템 재고와 실제 재고 불일치.

조치:
- 실재고 다시 확인 (3회)
- 시스템 수정은 매니저 권한 필요
- 베스트셀러 SKU 부족 시 인접 매장 이관 요청 (본사 SCM 시스템)

### §4.2 신상품 등록 누락

본사에서 자동 동기화. 24시간 지연 시 본사 MD에 문의.

## §5 환불 처리

### §5.1 일반 환불 (구매 7일 이내)

- 영수증 확인 → 시스템 환불 처리 → 환불 사유 코드 입력
- 카드 환불 시 동일 카드로 처리 (다른 카드 환불 불가)

### §5.2 환불 폭주 (REFUND 알림 발동 시)

이상 패턴 의심 — 매니저 호출.
하루 50건 이상 환불 시 본사 감사 알림 자동 발송.

## §6 네트워크 장애

### §6.1 매장 인터넷 끊김

조치:
1. 라우터 power cycle
2. 5분 후 미복구 시 ISP 고객센터 (KT 100 / SK 106)
3. 백업 LTE 라우터 활성화 (매장 카운터 보관)
4. 결제는 LTE 단말로 진행 (속도 저하 감안)

## §7 직원 권한

### §7.1 환불 권한

- 일반 직원: 5만원 이하 환불만 가능
- 매니저: 모든 환불 + 가격 수정
- 점장: 매장 운영 전체 권한

### §7.2 교대 시 POS 로그아웃

교대 시 반드시 본인 ID 로그아웃 → 다음 직원 ID 로그인.
로그아웃 누락 시 매출 귀속 오류 발생.

## §8 본사 연락처

| 부서 | 연락처 | 업무 시간 |
|---|---|---|
| IT 운영 (POS 장애) | 010-0000-1234 | 09:00 ~ 22:00 |
| SCM (재고·물류) | 010-0000-5678 | 09:00 ~ 18:00 |
| MD (상품 등록) | 010-0000-9012 | 09:00 ~ 18:00 |
| 감사 (이상 거래) | 010-0000-3456 | 09:00 ~ 18:00 |

## §9 야간·휴일 비상 연락

- 위 부서 부재 시: 본사 비상 라인 1588-0000
- 카드 단말 24시간 지원: VAN사 1588-1234
