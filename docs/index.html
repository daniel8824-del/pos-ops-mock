MCP 개발 | 도구를 연결하는 서버

학습 목표
MCP 서버를 직접 한 파일로 만들고, 학습자 본인 Copilot/Claude Code에 mcp.json 1줄로 연결. 3 tool (get_logs · detect_anomaly · create_ticket)이 자연어 한 줄로 자동 호출되는지 확인.

1MCP 3 슬롯

MCP는 Host(AI 앱) · Client(연결 담당) · Server(도구 제공자) 3 역할 구조. 우리가 13차시에 만드는 건 Server.

  • Host | Claude Code · Copilot · Cursor 같은 AI 앱
  • Client | Host 안에서 server 한 곳에 1:1 연결
  • Server | 도구 · 데이터 · 안내문 노출 (우리가 만드는 것)

Server가 노출하는 건 3 슬롯:

슬롯역할예시
tool실제 함수 | Python/Node 호출 가능get_logs(store, since)
resource정적/동적 데이터 | 매뉴얼·thresholdpos_runbook.md
prompt안내 템플릿 | Claude Code 스킬과 동일 역할"이상 탐지 → 진단 → 티켓"

훅 자동화 | 운영팀 가드레일

학습 목표
훅 3종 (PreToolUse · PostToolUse · SessionStart)으로 운영 가드레일·자동 알림·세션 brief를 시연. 학습자 본인 settings.json에 복사 1줄로 작동.

1훅 3 종류 + 발동 시점

종류시점역할
PreToolUsetool 호출 직전가드레일 | 위험 인자·짧은 제목·중복 차단
PostToolUsetool 호출 직후알림·후속 작업 | 임계 초과 시 webhook
SessionStart세션 시작 시점brief | 어제 운영 요약 자동 출력

2실습 ① | hooks.json 복사

# 본인 settings.json 의 hooks 섹션에 추가
{
  "hooks": {
    "PreToolUse": [{
      "matcher": "mcp__pos-ops__create_ticket",
      "hooks": [{"type":"command","command":"python3 $POS_OPS_ROOT/hooks/guard_ticket.py"}]
    }],
    "PostToolUse": [{
      "matcher": "mcp__pos-ops__detect_anomaly",
      "hooks": [{"type":"command","command":"python3 $POS_OPS_ROOT/hooks/on_anomaly.py"}]
    }],
    "SessionStart": [{
      "hooks": [{"type":"command","command":"python3 $POS_OPS_ROOT/hooks/morning_brief.py"}]
    }]
  }
}

3실습 ② | 가드레일 | 짧은 제목 차단

# 짧은 title은 자동 거부
echo '{"tool_args":{"title":"ab","body":"."}}' | \
  python3 hooks/guard_ticket.py
# → {"decision":"block","reason":"title 너무 짧음 (2자) | 5자 이상 필요"}
# → exit 2 (Claude Code 표준 block code)

4실습 ③ | 자동 알림 | 임계 초과

echo '{"tool_result":{"top_issue":"POS_DOWN","anomalies":{"POS_DOWN":15}}}' | \
  python3 hooks/on_anomaly.py
# 🚨 [HOOK] POS 운영 알림 | TOP ISSUE POS_DOWN (15건)
#   영향 매장: ['SEL-001']
#   권장: anomaly-triage skill 실행 또는 create_ticket 호출

5실습 ④ | SessionStart | 어제 brief

python3 hooks/morning_brief.py
# ☀ [HOOK] Morning Brief | 2026-05-13
#   거래 8,181 · 매출 ₩347,640,500 · 이상 12.9%
#   주의 매장 Top 3 (이상 비율):
#     - GYG-001  14.5% (113/777)
#     - SEL-001  14.1% (128/908)
#     - ICN-001  13.5% (108/802)

✓ 14차시 체크포인트

  • guard_ticket → 짧은 title block 동작 (exit 2)
  • on_anomaly → 임계 초과 시 stdout 알림 / 미만 시 silent
  • morning_brief → 어제 매장 Top 3 출력
